# Heart Disease Prediction using Machine Learning

An end-to-end Machine Learning project evaluating diagnostic health metrics to predict the presence of heart disease using Logistic Regression and K-Nearest Neighbors (KNN).

---

## 📌 Project Overview
Heart disease is one of the leading causes of morbidity globally. Early detection and accurate risk prediction can assist medical professionals in making timely clinical decisions. 

This project explores patient diagnostic data, performs Exploratory Data Analysis (EDA), applies data preprocessing, and builds classification models to accurately predict heart disease risk.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn
* **Development Environment:** Kaggle Notebooks / Jupyter Notebook

---

## 📊 Key Results & Performance
Among the models tested, **K-Nearest Neighbors (KNN)** demonstrated superior performance on the evaluation dataset:

| Metric | Score |
| :--- | :--- |
| **Best Model** | **KNN** |
| **Accuracy** | 86.3% |
| **Precision** | 87.4% |
| **Recall** | 85.7% |
| **F1-Score** | **0.865** |
| **ROC-AUC** | **0.963** |
